# **App Name**: Novae Audition Hub

## Core Features:

- Guided Application Form: Implement a multi-step form using Next.js for a smooth user experience, guiding applicants through each stage of the audition process.
- Application Status Tracker: Develop a real-time application status tracker where applicants can check their submission status using a verification code sent to their email.
- Responsive Design: Ensure responsive design for all pages, adapting seamlessly to various screen sizes and devices.

## Style Guidelines:

- Primary color: Use a deep navy blue (#1A237E) to convey professionalism and stability.
- Secondary color: Implement a clean white (#FFFFFF) for backgrounds to ensure readability and a modern aesthetic.
- Accent: Introduce a vibrant teal (#26A69A) for interactive elements like buttons and links to draw attention.
- Employ a grid-based layout for consistent alignment and spacing across all sections.
- Incorporate minimalist icons in teal (#26A69A) to represent different audition categories and navigation items.
